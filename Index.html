QuickMove AI Ops Inbox

Turn relocation messages into structured, reviewable updates using Gemini AI. Human approval is required before changes are made to operational records.

3 AI analysis

Paste a message and select Analyze with Gemini.

AI output may be incomplete or incorrect. Check every field, particularly the date, status and target task, before approval.

4 Review and decide

Choose the correct task and review the proposed fields. Only the task you select can be updated.

Analyze a message to start the review.

Approval can update the selected task's status, blocker and next action when those fields are supplied. Rejection should leave the task unchanged. Both decisions are intended to be recorded in Audit Log.
