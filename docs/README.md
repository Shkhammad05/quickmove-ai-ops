# QuickMove AI Ops

## Overview
QuickMove AI Ops is an AI-assisted operations tool designed to help relocation coordinators review updates and manage relocation tasks.

## Problem
Relocation teams often coordinate through WhatsApp, emails, and spreadsheets. Manually transferring updates can cause delays, missed follow-ups, and inconsistent records.

## Solution
The tool analyzes an operations message, generates a proposed update, and allows a coordinator to review, approve, or reject it.

## Key Features
- AI-assisted message analysis
- Relocation and task matching
- Human approval before task updates
- Audit log for approval decisions
- Google Sheets integration through Google Apps Script

## Technology Stack
- Google Apps Script
- Google Sheets
- HTML, CSS, and JavaScript
- Google Gemini API
